# SecondChance Backend Capstone

SecondChance is a full-stack capstone project for giving away and reusing household items. The repository contains the Node.js/Express backend, MongoDB import utilities, the provided frontend, and a sentiment-analysis service.

## Main APIs

- `GET /api/secondchance/items`
- `GET /api/secondchance/items/:id`
- `POST /api/secondchance/items`
- `PUT /api/secondchance/items/:id`
- `DELETE /api/secondchance/items/:id`
- `GET /api/secondchance/search`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `PUT /api/auth/update`

See `user-story.md` for the project user-story template.
